# 단어|왜 이 한자들인지|예문|예문 번역
哎||哎，你等等我！|야, 나 좀 기다려!
哎呀|哎(어) + 呀(아) → 놀람을 나타내는 소리 = 아이고|哎呀，我忘带钥匙了！|아이고, 열쇠를 안 가져왔네!
唉||唉，又下雨了。|휴, 또 비가 오네.
爱护|爱(사랑하다) + 护(보호하다) → 아끼고 보호하다|我们要爱护小动物。|작은 동물을 아끼고 보호해야 해요.
安||他一个人在外地，我很不安。|그가 혼자 타지에 있어서 마음이 불안해요.
安慰|安(편안하게 하다) + 慰(위로하다) → 위로하다|朋友安慰了我很久。|친구가 오랫동안 나를 위로해 줬어요.
安装|安(놓다) + 装(설치하다) → 설치하다|我在手机上安装了一个新软件。|휴대폰에 새 앱을 설치했어요.
暗||房间里太暗了，开灯吧。|방이 너무 어두워요, 불 켜요.
熬夜|熬(오래 견디다) + 夜(밤) → 밤을 견디다 = 밤을 새우다|经常熬夜对身体不好。|자주 밤을 새우면 몸에 안 좋아요.
把握|把(잡다) + 握(쥐다) → 꽉 잡다 = 자신감, 파악하다|这次考试我很有把握。|이번 시험은 자신 있어요.
白||我白跑了一趟。|헛걸음을 했어요.
半夜|半(반) + 夜(밤) → 한밤중|他半夜才回家。|그는 한밤중에야 집에 왔어요.
傍晚|傍(가깝다) + 晚(저녁) → 저녁에 가까운 때 = 해 질 무렵|傍晚的时候我们去散步吧。|해 질 무렵에 산책 가요.
包裹|包(싸다) + 裹(감싸다) → 감싼 것 = 소포|我去邮局寄包裹。|우체국에 소포 부치러 가요.
包含|包(싸다) + 含(머금다) → 포함하다|房费包含早餐。|숙박비에 아침 식사가 포함돼요.
包括|包(싸다) + 括(묶다) → 포괄하다|大家都去，包括我。|나를 포함해서 모두 가요.
包装|包(싸다) + 装(꾸미다) → 포장하다|这个礼物包装得很漂亮。|이 선물은 예쁘게 포장됐어요.
薄||这本书很薄。|이 책은 아주 얇아요.
宝||这个孩子是父母的宝。|이 아이는 부모님의 보물이에요.
宝贝|宝(보배) + 贝(조개, 재물) → 보물, 귀염둥이|宝贝，快来吃饭！|우리 아기, 얼른 밥 먹으러 와!
宝贵|宝(보배) + 贵(귀하다) → 귀중하다|时间是很宝贵的。|시간은 아주 귀중해요.
保||请保好你的东西。|물건을 잘 지키세요.
保安|保(지키다) + 安(안전) → 안전을 지키는 사람 = 경비원|小区门口有保安。|아파트 단지 입구에 경비원이 있어요.
保持|保(지키다) + 持(가지다) → 유지하다|请保持安静。|조용히 해 주세요.
保存|保(지키다) + 存(두다) → 보존하다|请保存好这张照片。|이 사진을 잘 보관하세요.
保留|保(지키다) + 留(남기다) → 남겨 두다|这个座位给你保留着。|이 자리는 당신을 위해 남겨 뒀어요.
保险|保(지키다) + 险(위험) → 위험에서 지키는 것 = 보험|我买了旅游保险。|여행자 보험을 들었어요.
保质期|保(지키다) + 质(품질) + 期(기간) → 품질을 지키는 기간 = 유통 기한|这瓶牛奶的保质期到明天。|이 우유는 유통 기한이 내일까지예요.
报到|报(알리다) + 到(도착하다) → 도착을 알리다 = 등록하다|新同学九月一号来学校报到。|신입생은 9월 1일에 학교에 등록하러 와요.
报道|报(알리다) + 道(말하다) → 보도하다|电视报道了这条新闻。|텔레비전에서 이 뉴스를 보도했어요.
报告|报(알리다) + 告(고하다) → 보고하다, 보고서|我明天要交一份报告。|내일 보고서를 하나 내야 해요.
报警|报(알리다) + 警(경찰) → 경찰에 알리다|有人偷东西，快报警！|누가 물건을 훔쳐요, 빨리 신고해요!
抱怨|抱(품다) + 怨(원망) → 원망을 품다 = 불평하다|他总是抱怨工作太累。|그는 늘 일이 너무 힘들다고 불평해요.
暴雨|暴(사나운) + 雨(비) → 폭우|明天有暴雨，别出门了。|내일 폭우가 오니 나가지 마요.
背后|背(등) + 后(뒤) → 등 뒤 = 배후|不要在背后说别人。|뒤에서 남 이야기를 하지 마세요.
背景|背(등) + 景(경치) → 뒤의 경치 = 배경|这张照片的背景很美。|이 사진은 배경이 아름다워요.
被子|被(이불) + 子(명사 꼬리) → 이불|天冷了，盖厚被子吧。|날이 추우니 두꺼운 이불 덮어요.
本地|本(이, 근본) + 地(땅) → 이 고장 = 현지|他是本地人。|그는 현지 사람이에요.
本领|本(근본) + 领(거느리다) → 능력|他有很大的本领。|그는 능력이 대단해요.
本人|本(이, 자기) + 人(사람) → 본인|这件事要本人来办。|이 일은 본인이 직접 처리해야 해요.
本质|本(근본) + 质(바탕) → 본질|我们要看到问题的本质。|문제의 본질을 봐야 해요.
比分|比(겨루다) + 分(점수) → 점수|现在的比分是二比一。|현재 점수는 2대 1이에요.
比例|比(견주다) + 例(비율) → 비례, 비율|我们班男女比例差不多。|우리 반은 남녀 비율이 비슷해요.
比喻|比(견주다) + 喻(깨우치다) → 비유하다|人们常把老师比喻成园丁。|사람들은 흔히 선생님을 정원사에 비유해요.
彼此|彼(저) + 此(이) → 저쪽과 이쪽 = 서로|我们彼此都很了解。|우리는 서로를 잘 알아요.
必||他明天必来。|그는 내일 반드시 와요.
必然|必(반드시) + 然(그러하다) → 필연적이다|努力必然会有结果。|노력하면 반드시 결과가 있어요.
必需|必(반드시) + 需(필요) → 반드시 필요하다|水是生活必需品。|물은 생활 필수품이에요.
必要|必(반드시) + 要(요긴하다) → 필요하다|没有必要担心。|걱정할 필요 없어요.
毕竟|毕(마치다) + 竟(끝) → 결국 끝에 가서는 = 어쨌든|他毕竟还是个孩子。|그는 어쨌든 아직 아이예요.
闭幕式|闭(닫다) + 幕(막) + 式(의식) → 막을 닫는 의식 = 폐막식|闭幕式很精彩。|폐막식이 아주 멋졌어요.
避免|避(피하다) + 免(면하다) → 피하다|我们要避免犯同样的错误。|같은 실수를 하지 않도록 해야 해요.
变动|变(변하다) + 动(움직이다) → 변동하다|计划有变动。|계획에 변동이 있어요.
便||一下课他便回家了。|수업이 끝나자 그는 곧 집에 갔어요.
便利|便(편하다) + 利(이롭다) → 편리하다|这里的交通很便利。|이곳 교통은 편리해요.
便利店|便利(편리) + 店(가게) → 편의점|楼下有一家便利店。|아래층에 편의점이 있어요.
标题|标(표) + 题(제목) → 제목|这篇文章的标题很有意思。|이 글은 제목이 재미있어요.
标志|标(표) + 志(기록) → 표지, 상징|这是这个城市的标志。|이건 이 도시의 상징이에요.
表达|表(드러내다) + 达(이르다) → 표현하다|我不知道怎么表达我的感谢。|감사를 어떻게 표현해야 할지 모르겠어요.
表面|表(겉) + 面(면) → 표면|他表面上很高兴。|그는 겉으로는 기뻐 보여요.
表明|表(드러내다) + 明(밝히다) → 표명하다|他表明了自己的态度。|그는 자신의 입장을 밝혔어요.
表情|表(드러내다) + 情(감정) → 표정|他的表情很奇怪。|그의 표정이 이상해요.
饼||我早上吃了一个饼。|아침에 전병 하나를 먹었어요.
病房|病(병) + 房(방) → 병실|爷爷住在三号病房。|할아버지는 3호 병실에 계세요.
病情|病(병) + 情(상황) → 병세|他的病情好多了。|그의 병세가 많이 좋아졌어요.
拨打|拨(돌리다) + 打(걸다) → 전화를 걸다|有问题请拨打这个电话。|문제가 있으면 이 번호로 전화하세요.
玻璃|玻(유리) + 璃(유리) → 유리|小心，地上有碎玻璃。|조심해요, 바닥에 유리 조각이 있어요.
博物馆|博(넓다) + 物(물건) + 馆(집) → 온갖 물건을 모은 집 = 박물관|我们去参观博物馆吧。|박물관 구경 가요.
补充|补(채우다) + 充(가득하다) → 보충하다|我来补充一点。|제가 조금 보충할게요.
不得了|不(아니다) + 得了(끝나다) → 수습할 수 없다 = 큰일이다, 대단하다|他高兴得不得了。|그는 엄청나게 기뻐해요.
不利|不(아니다) + 利(이롭다) → 불리하다|天气对比赛很不利。|날씨가 시합에 불리해요.
不良|不(아니다) + 良(좋다) → 좋지 않다|抽烟是不良习惯。|흡연은 나쁜 습관이에요.
不然|不(아니다) + 然(그러하다) → 그렇지 않으면|快走吧，不然要迟到了。|빨리 가요, 안 그러면 늦어요.
不幸|不(아니다) + 幸(다행) → 불행하다|这真是一件不幸的事。|이건 정말 불행한 일이에요.
不要紧|不(아니다) + 要紧(중요하다) → 대수롭지 않다 = 괜찮다|只是小感冒，不要紧。|가벼운 감기일 뿐이라 괜찮아요.
不足|不(아니다) + 足(넉넉하다) → 부족하다|我们的时间不足。|우리는 시간이 부족해요.
步行|步(걸음) + 行(가다) → 걸어가다|从这儿步行十分钟就到了。|여기서 걸어서 10분이면 도착해요.
裁判|裁(마르다, 결단하다) + 判(판단하다) → 심판|他是这场比赛的裁判。|그는 이 경기의 심판이에요.
采访|采(캐다) + 访(찾다) → 찾아가 캐묻다 = 인터뷰하다|记者采访了这位作家。|기자가 이 작가를 인터뷰했어요.
采取|采(캐다) + 取(가지다) → 채택하다|我们要采取措施。|우리는 조치를 취해야 해요.
采用|采(캐다) + 用(쓰다) → 채택하여 쓰다|公司采用了他的建议。|회사는 그의 제안을 채택했어요.
彩色|彩(채색) + 色(빛깔) → 컬러|我想打印彩色的照片。|컬러 사진을 인쇄하고 싶어요.
参考|参(참여하다) + 考(살피다) → 참고하다|这本书可以作为参考。|이 책을 참고로 삼을 수 있어요.
参与|参(참여하다) + 与(더불다) → 참여하다|很多人参与了这次活动。|많은 사람이 이번 활동에 참여했어요.
餐饮|餐(식사) + 饮(마시다) → 먹고 마시는 것 = 요식업|他在餐饮公司工作。|그는 요식업 회사에서 일해요.
藏||他把钱藏在书里。|그는 돈을 책 속에 숨겼어요.
操作|操(다루다) + 作(하다) → 조작하다|这台机器很容易操作。|이 기계는 조작하기 쉬워요.
册||这套书一共有五册。|이 책 시리즈는 모두 다섯 권이에요.
测||我们测一下体温吧。|체온을 재 봐요.
测试|测(재다) + 试(시험) → 테스트하다|明天有汉语测试。|내일 중국어 테스트가 있어요.
曾||我曾在北京住过两年。|나는 예전에 베이징에서 2년 살았어요.
曾经|曾(일찍이) + 经(지나다) → 일찍이 겪다|我曾经去过那里。|나는 예전에 거기 가 본 적이 있어요.
叉子|叉(갈래) + 子(명사 꼬리) → 포크|请给我一把叉子。|포크 하나 주세요.
插||请把花插在瓶子里。|꽃을 병에 꽂아 주세요.
差别|差(차이) + 别(다르다) → 차이|这两个词有什么差别？|이 두 단어는 무슨 차이가 있어요?
差距|差(차이) + 距(거리) → 격차|城市和农村的差距很大。|도시와 농촌의 격차가 커요.
拆||请帮我拆一下这个包裹。|이 소포 좀 뜯어 주세요.
产||这个地方产茶叶。|이 지역은 찻잎이 나요.
产量|产(생산) + 量(양) → 생산량|今年的产量增加了。|올해 생산량이 늘었어요.
产品|产(생산) + 品(물건) → 제품|这是我们公司的新产品。|이건 우리 회사의 신제품이에요.
产业|产(생산) + 业(일) → 산업|旅游产业发展得很快。|관광 산업이 빠르게 발전하고 있어요.
尝试|尝(맛보다) + 试(시도하다) → 시도하다|你可以尝试一下新方法。|새로운 방법을 한번 시도해 봐요.
常识|常(늘) + 识(앎) → 늘 아는 것 = 상식|这是一个生活常识。|이건 생활 상식이에요.
场所|场(마당) + 所(곳) → 장소|公共场所不能抽烟。|공공장소에서는 담배를 피울 수 없어요.
超||这个月的花费超了预算。|이번 달 지출이 예산을 넘었어요.
超出|超(넘다) + 出(나가다) → 초과하다|这个价格超出了我的预算。|이 가격은 내 예산을 넘었어요.
超级|超(뛰어넘다) + 级(등급) → 슈퍼, 아주|这家店的菜超级好吃。|이 가게 음식은 엄청 맛있어요.
超速|超(넘다) + 速(속도) → 과속하다|开车不要超速。|운전할 때 과속하지 마세요.
朝||这个房间朝南。|이 방은 남향이에요.
吵||外面太吵了，我睡不着。|밖이 너무 시끄러워서 잠이 안 와요.
炒||妈妈在炒菜。|엄마가 요리를 볶고 있어요.
车祸|车(차) + 祸(재앙) → 교통사고|这里发生了一起车祸。|여기서 교통사고가 났어요.
车库|车(차) + 库(창고) → 차고|我把车停在车库里。|차를 차고에 세웠어요.
车辆|车(차) + 辆(대) → 차량|路上的车辆很多。|길에 차량이 많아요.
车厢|车(차) + 厢(칸) → 객실, 칸|我在第三节车厢。|나는 3호차에 있어요.
车主|车(차) + 主(주인) → 차주|这辆车的车主是谁？|이 차 주인이 누구예요?
彻底|彻(꿰뚫다) + 底(바닥) → 바닥까지 꿰뚫다 = 철저하다|我把房间彻底打扫了一遍。|방을 철저하게 청소했어요.
沉||这个箱子很沉。|이 상자는 아주 무거워요.
