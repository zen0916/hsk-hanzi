# 단어|왜 이 한자들인지|예문|예문 번역
阿姨|阿(친근하게 부르는 말) + 姨(이모) → 이모님 = 아주머니|阿姨，请问这个多少钱？|아주머니, 이거 얼마예요?
矮||我比哥哥矮一点儿。|나는 형보다 키가 좀 작아요.
爱人|爱(사랑하다) + 人(사람) → 사랑하는 사람 = 배우자|我爱人在银行工作。|제 배우자는 은행에서 일해요.
安静|安(편안하다) + 静(고요하다) → 조용하다|图书馆里很安静。|도서관 안은 아주 조용해요.
安全|安(편안하다) + 全(온전하다) → 편안하고 온전하다 = 안전하다|晚上一个人回家不安全。|밤에 혼자 집에 가는 건 안전하지 않아요.
把||请把门关上。|문 좀 닫아 주세요.
班级|班(반) + 级(등급) → 학급|我们班级有四十个人。|우리 학급은 40명이에요.
搬||这个箱子太重了，我搬不动。|이 상자는 너무 무거워서 못 옮기겠어요.
搬家|搬(옮기다) + 家(집) → 집을 옮기다 = 이사하다|我们下个月搬家。|우리는 다음 달에 이사해요.
办||这件事我来办。|이 일은 제가 처리할게요.
办法|办(처리하다) + 法(방법) → 처리하는 방법|你有什么好办法吗？|좋은 방법 있어요?
办公室|办公(공무를 보다) + 室(방) → 사무실|经理在办公室。|매니저님은 사무실에 계세요.
半天|半(반) + 天(하루) → 반나절 = 한참 동안|我等了你半天。|한참 동안 기다렸어요.
帮助|帮(돕다) + 助(돕다) → 같은 뜻을 겹쳐 = 돕다, 도움|谢谢你的帮助。|도와줘서 고마워요.
饱||我吃饱了。|배불러요.
报纸|报(알리다) + 纸(종이) → 소식을 알리는 종이 = 신문|爷爷每天看报纸。|할아버지는 매일 신문을 보세요.
北||银行在学校北边。|은행은 학교 북쪽에 있어요.
北方|北(북) + 方(방향) → 북방, 북쪽 지역|北方的冬天很冷。|북쪽 지방의 겨울은 아주 추워요.
被||我的自行车被人骑走了。|누가 내 자전거를 타고 가 버렸어요.
比较|比(견주다) + 较(견주다) → 비교하다, 비교적|今天比较冷。|오늘은 비교적 추워요.
比如|比(비유하다) + 如(~와 같다) → 예를 들면|我喜欢运动，比如游泳、跑步。|나는 운동을 좋아해요, 예를 들면 수영, 달리기요.
比赛|比(겨루다) + 赛(겨루다) → 시합|明天有足球比赛。|내일 축구 시합이 있어요.
笔记|笔(붓) + 记(기록하다) → 붓으로 기록한 것 = 필기|上课的时候要做笔记。|수업 시간에 필기해야 해요.
笔记本|笔记(필기) + 本(책) → 필기하는 책 = 노트, 노트북|我买了一个新的笔记本。|새 노트를 하나 샀어요.
必须|必(반드시) + 须(모름지기) → 반드시 ~해야 한다|明天你必须早点儿来。|내일 반드시 일찍 와야 해요.
变||他变了很多。|그는 많이 변했어요.
变成|变(변하다) + 成(이루다) → ~로 변하다|水变成了冰。|물이 얼음으로 변했어요.
变化|变(변하다) + 化(되다) → 변화|这几年北京变化很大。|요 몇 년 베이징은 변화가 커요.
遍||请再说一遍。|한 번 더 말해 주세요.
表演|表(드러내다) + 演(펼치다) → 드러내어 펼치다 = 공연|孩子们的表演很精彩。|아이들의 공연은 아주 멋졌어요.
别的|别(다른) + 的(것) → 다른 것|你还要别的吗？|다른 것도 필요해요?
别人|别(다른) + 人(사람) → 다른 사람|不要拿别人的东西。|남의 물건을 가져가지 마세요.
宾馆|宾(손님) + 馆(집) → 손님이 묵는 집 = 호텔|我们住在火车站旁边的宾馆。|우리는 기차역 옆 호텔에 묵어요.
冰||冬天河上有冰。|겨울에 강 위에 얼음이 있어요.
冰箱|冰(얼음) + 箱(상자) → 얼음 상자 = 냉장고|牛奶在冰箱里。|우유는 냉장고 안에 있어요.
病人|病(병) + 人(사람) → 환자|医生正在看病人。|의사가 환자를 진찰하고 있어요.
不但|不(아니다) + 但(다만) → 다만 ~뿐이 아니라|她不但漂亮，而且很聪明。|그녀는 예쁠 뿐만 아니라 똑똑해요.
不见|不(아니다) + 见(보이다) → 보이지 않다|我的钥匙不见了。|열쇠가 안 보여요.
不久|不(아니다) + 久(오래다) → 오래지 않아 = 머지않아|不久他就回来了。|머지않아 그가 돌아왔어요.
不同|不(아니다) + 同(같다) → 같지 않다 = 다르다|我们的爱好不同。|우리는 취미가 달라요.
不行|不(아니다) + 行(되다) → 안 된다|这样做不行。|이렇게 하면 안 돼요.
不用|不(아니다) + 用(쓰다, 필요하다) → ~할 필요 없다|你不用担心。|걱정할 필요 없어요.
才||他十点才起床。|그는 10시에야 일어났어요.
菜单|菜(요리) + 单(목록) → 요리 목록 = 메뉴|服务员，请给我菜单。|여기요, 메뉴판 주세요.
参加|参(참여하다) + 加(더하다) → 참가하다|我想参加这个比赛。|이 시합에 참가하고 싶어요.
草||草地上的草很绿。|잔디밭의 풀이 아주 푸르러요.
草地|草(풀) + 地(땅) → 풀밭|孩子们在草地上玩儿。|아이들이 잔디밭에서 놀아요.
层||我住在十二层。|나는 12층에 살아요.
查||我用手机查一下。|휴대폰으로 좀 찾아볼게요.
差||我的汉语还差得远。|제 중국어는 아직 많이 부족해요.
差不多|差(차이) + 不多(많지 않다) → 차이가 많지 않다 = 거의, 비슷하다|我们俩差不多高。|우리 둘은 키가 비슷해요.
尝||你尝尝这个菜。|이 요리 맛 좀 봐요.
常||欢迎常来玩儿。|자주 놀러 오세요.
常常|常(늘)을 두 번 → 자주|我常常去公园散步。|나는 자주 공원에 산책하러 가요.
常见|常(늘) + 见(보이다) → 흔히 보이다|这是一种常见的病。|이건 흔한 병이에요.
常用|常(늘) + 用(쓰다) → 자주 쓰다|这些都是常用的汉字。|이것들은 다 자주 쓰는 한자예요.
衬衫|衬(속에 받쳐 입다) + 衫(웃옷) → 셔츠|他穿着白衬衫。|그는 흰 셔츠를 입고 있어요.
成绩|成(이루다) + 绩(공적) → 이룬 결과 = 성적|她的成绩很好。|그녀는 성적이 좋아요.
城市|城(성) + 市(시장) → 성과 시장이 있는 곳 = 도시|上海是一个大城市。|상하이는 대도시예요.
迟到|迟(늦다) + 到(도착하다) → 늦게 도착하다 = 지각하다|对不起，我迟到了。|죄송해요, 지각했어요.
出发|出(나가다) + 发(떠나다) → 출발하다|我们几点出发？|우리 몇 시에 출발해요?
出生|出(나오다) + 生(태어나다) → 태어나다|我出生在首尔。|나는 서울에서 태어났어요.
出院|出(나가다) + 院(병원) → 병원에서 나가다 = 퇴원하다|爷爷明天出院。|할아버지는 내일 퇴원하세요.
初中|初(처음) + 中(중학교) → 처음 단계 중학교 = 중학교|我弟弟上初中了。|내 남동생은 중학생이 됐어요.
除了|除(덜다) + 了(완료) → ~을 빼고|除了他，大家都来了。|그 사람 빼고 모두 왔어요.
船||我们坐船去那个岛。|우리는 배를 타고 그 섬에 가요.
春天|春(봄) + 天(날, 계절) → 봄|春天到了，花都开了。|봄이 와서 꽃이 다 피었어요.
词典|词(단어) + 典(책, 법전) → 단어 책 = 사전|这个字我不认识，查查词典吧。|이 글자를 모르니 사전을 찾아봐요.
聪明|聪(귀가 밝다) + 明(눈이 밝다) → 귀와 눈이 밝다 = 똑똑하다|这个孩子很聪明。|이 아이는 아주 똑똑해요.
打扫|打(하다) + 扫(쓸다) → 쓸고 닦다 = 청소하다|周末我要打扫房间。|주말에 방 청소를 해야 해요.
打算|打(하다) + 算(셈하다) → 셈해 두다 = 계획하다|你打算什么时候去中国？|언제 중국에 갈 계획이에요?
大概|大(큰) + 概(대강) → 대강, 아마|他大概八点到。|그는 아마 8시에 도착할 거예요.
大人|大(큰) + 人(사람) → 다 큰 사람 = 어른|这是大人的事，你别管。|이건 어른 일이니 신경 쓰지 마.
大小|大(크다) + 小(작다) → 크고 작음 = 크기|这双鞋大小正合适。|이 신발은 크기가 딱 맞아요.
大熊猫|大(큰) + 熊(곰) + 猫(고양이) → 고양이 얼굴의 큰 곰 = 판다|我在动物园看到了大熊猫。|동물원에서 판다를 봤어요.
大衣|大(큰) + 衣(옷) → 큰 옷 = 외투|天冷了，穿上大衣吧。|날이 추워졌으니 코트 입어요.
带||别忘了带护照。|여권 챙기는 거 잊지 마요.
担心|担(짊어지다) + 心(마음) → 마음에 짐을 지다 = 걱정하다|妈妈很担心我。|엄마는 나를 많이 걱정해요.
蛋糕|蛋(달걀) + 糕(떡) → 달걀로 만든 떡 = 케이크|生日的时候要吃蛋糕。|생일에는 케이크를 먹어요.
当然|当(마땅하다) + 然(그러하다) → 마땅히 그러하다 = 당연히|你来吗？当然来！|올 거예요? 당연히 가죠!
到处|到(이르다) + 处(곳) → 이르는 곳마다 = 곳곳에|公园里到处都是花。|공원 곳곳에 꽃이 있어요.
地点|地(땅) + 点(점) → 땅의 한 점 = 장소|请告诉我见面的地点。|만날 장소를 알려 주세요.
地方|地(땅) + 方(방향, 곳) → 곳|这个地方很漂亮。|여기 정말 예쁜 곳이네요.
地图|地(땅) + 图(그림) → 땅을 그린 그림 = 지도|我在手机上看地图。|휴대폰으로 지도를 봐요.
的话|的(~의) + 话(말) → ~라는 말이라면 = ~라면|明天下雨的话，我们就不去了。|내일 비가 오면 우리 안 갈게요.
得到|得(얻다) + 到(이르다) → 얻어 내다|他得到了大家的帮助。|그는 모두의 도움을 받았어요.
得分|得(얻다) + 分(점수) → 점수를 얻다|他这次考试得分很高。|그는 이번 시험에서 점수가 높아요.
灯||请把灯关了。|불 좀 꺼 주세요.
电||没电了，手机关机了。|배터리가 없어서 휴대폰이 꺼졌어요.
电梯|电(전기) + 梯(사다리) → 전기 사다리 = 엘리베이터|我们坐电梯上去吧。|엘리베이터 타고 올라가요.
丢||我的钱包丢了。|지갑을 잃어버렸어요.
东||太阳从东边出来。|해는 동쪽에서 떠요.
东北|东(동) + 北(북) → 동북|他是东北人。|그는 동북 지방 사람이에요.
东方|东(동) + 方(방향) → 동방, 동쪽|东方的天空开始亮了。|동쪽 하늘이 밝아지기 시작했어요.
东南|东(동) + 南(남) → 동남|上海在中国的东南。|상하이는 중국 동남쪽에 있어요.
冬天|冬(겨울) + 天(계절) → 겨울|我最喜欢冬天。|나는 겨울을 제일 좋아해요.
懂得|懂(알다) + 得(얻다) → 깨달아 알다|他懂得很多道理。|그는 많은 이치를 알아요.
动物|动(움직이다) + 物(것) → 움직이는 것 = 동물|你喜欢什么动物？|무슨 동물 좋아해요?
动物园|动物(동물) + 园(동산) → 동물원|周末我们去动物园吧。|주말에 동물원 가자.
短||这条裤子太短了。|이 바지는 너무 짧아요.
短裤|短(짧다) + 裤(바지) → 반바지|夏天我喜欢穿短裤。|여름에는 반바지 입는 걸 좋아해요.
段||请读一下这段课文。|이 단락 좀 읽어 주세요.
锻炼|锻(쇠를 두드리다) + 炼(불에 달구다) → 쇠를 단련하듯 = 운동하다|我每天早上锻炼身体。|나는 매일 아침 운동해요.
对话|对(마주하다) + 话(말) → 마주 보고 하는 말 = 대화|请两个人练习这段对话。|두 사람이 이 대화를 연습해 보세요.
饿||我饿了，我们去吃饭吧。|배고파요, 밥 먹으러 가요.
而且|而(그리고) + 且(또) → 게다가|这家店很便宜，而且很好吃。|이 가게는 싸고 게다가 맛있어요.
耳朵|耳(귀) + 朵(송이) → 귓바퀴 = 귀|兔子的耳朵很长。|토끼는 귀가 길어요.
耳机|耳(귀) + 机(기계) → 귀에 꽂는 기계 = 이어폰|我戴着耳机听音乐。|이어폰을 끼고 음악을 들어요.
发||我给你发了一条短信。|문자 하나 보냈어요.
发烧|发(나다) + 烧(타다, 열) → 열이 나다|孩子发烧了。|아이가 열이 나요.
发生|发(일어나다) + 生(생기다) → 발생하다|这里发生了什么事？|여기 무슨 일이 생겼어요?
发现|发(드러내다) + 现(나타나다) → 발견하다|我发现他不在家。|그가 집에 없다는 걸 알았어요.
发展|发(펴다) + 展(펼치다) → 펼쳐 나가다 = 발전|这个城市发展得很快。|이 도시는 빠르게 발전했어요.
方便|方(방법) + 便(편하다) → 편리하다|地铁很方便。|지하철은 아주 편리해요.
方便面|方便(편리하다) + 面(국수) → 편리한 국수 = 라면|我晚上吃了方便面。|저녁에 라면을 먹었어요.
方法|方(방향) + 法(법) → 방법|你的学习方法很好。|당신의 공부 방법이 좋네요.
方向|方(방향) + 向(향하다) → 방향|我们走错方向了。|우리 방향을 잘못 왔어요.
房子|房(집) + 子(명사 꼬리) → 집|他买了一套新房子。|그는 새집을 샀어요.
放||请把书放在桌子上。|책을 책상 위에 놓아 주세요.
放假|放(놓다, 풀어주다) + 假(휴가) → 휴가를 주다 = 방학하다|学校七月放假。|학교는 7월에 방학해요.
放心|放(놓다) + 心(마음) → 마음을 놓다 = 안심하다|你放心，我会照顾好自己。|안심해요, 내 몸은 내가 잘 챙길게요.
放学|放(풀어주다) + 学(학교) → 학교에서 풀어주다 = 하교하다|孩子四点放学。|아이는 4시에 하교해요.
