# 단어|왜 이 한자들인지|예문|예문 번역
爱情|爱(사랑) + 情(감정) → 사랑의 감정|这是一个关于爱情的故事。|이건 사랑에 관한 이야기예요.
爱心|爱(사랑) + 心(마음) → 사랑하는 마음|她是一个很有爱心的人。|그녀는 마음이 따뜻한 사람이에요.
安检|安(안전) + 检(검사) → 안전 검사|坐飞机前要过安检。|비행기 타기 전에 보안 검사를 받아야 해요.
安排|安(놓다) + 排(배열하다) → 알맞게 놓고 배열하다 = 일정을 짜다|明天的工作我已经安排好了。|내일 업무는 이미 다 짜 놨어요.
按||请按一下这个按钮。|이 버튼 좀 눌러 주세요.
按时|按(따르다) + 时(시간) → 시간에 따라 = 제때에|请按时吃药。|제때 약을 드세요.
按照|按(따르다) + 照(비추다, 따르다) → ~에 따라|请按照老师说的做。|선생님 말씀대로 하세요.
白酒|白(희다) + 酒(술) → 맑은 술 = 고량주|他不喝白酒，只喝啤酒。|그는 고량주는 안 마시고 맥주만 마셔요.
办公|办(처리하다) + 公(공무) → 사무를 보다|经理在办公室办公。|매니저는 사무실에서 업무를 봐요.
办理|办(처리하다) + 理(다스리다) → 처리하다|我去银行办理一张卡。|은행에 카드 만들러 가요.
办事|办(처리하다) + 事(일) → 일을 처리하다|他办事很认真。|그는 일 처리가 꼼꼼해요.
棒||你说汉语说得真棒！|중국어 정말 잘하네요!
保护|保(지키다) + 护(보호하다) → 보호하다|我们要保护环境。|우리는 환경을 보호해야 해요.
保证|保(지키다) + 证(증명하다) → 지킬 것을 증명하다 = 보증하다|我保证明天不迟到。|내일 지각 안 한다고 약속해요.
报考|报(신청하다) + 考(시험) → 시험에 신청하다|他报考了北京大学。|그는 베이징대학에 응시했어요.
报名|报(알리다) + 名(이름) → 이름을 알리다 = 신청하다|我想报名参加比赛。|시합에 참가 신청하고 싶어요.
抱||妈妈抱着孩子。|엄마가 아이를 안고 있어요.
抱歉|抱(품다) + 歉(미안함) → 미안함을 품다|很抱歉，让你久等了。|오래 기다리게 해서 정말 죄송해요.
北部|北(북) + 部(부분) → 북부|这个城市在中国北部。|이 도시는 중국 북부에 있어요.
背||他每天背二十个生词。|그는 매일 새 단어 스무 개를 외워요.
背包|背(메다) + 包(가방) → 메는 가방 = 배낭|我的背包里有一本书。|내 배낭 안에 책이 한 권 있어요.
倍||这个房间比那个大两倍。|이 방은 저 방보다 두 배 커요.
本科|本(근본) + 科(과정) → 기본 과정 = 학부|他是本科生。|그는 학부생이에요.
本来|本(근본) + 来(오다) → 본래부터|我本来想去，后来没时间了。|원래 가려고 했는데 나중에 시간이 없었어요.
笨||我太笨了，又做错了。|나 너무 바보 같아, 또 틀렸어.
鼻子|鼻(코) + 子(명사 꼬리) → 코|他的鼻子很高。|그는 코가 높아요.
笔试|笔(붓) + 试(시험) → 붓으로 치는 시험 = 필기시험|明天上午有笔试。|내일 오전에 필기시험이 있어요.
毕业|毕(마치다) + 业(학업) → 학업을 마치다 = 졸업하다|我明年大学毕业。|나는 내년에 대학을 졸업해요.
毕业生|毕业(졸업) + 生(학생) → 졸업생|今年的毕业生很多。|올해는 졸업생이 많아요.
便于|便(편하다) + 于(~에) → ~하기에 편하다|这本词典很小，便于带。|이 사전은 작아서 들고 다니기 편해요.
标准|标(표) + 准(기준) → 표준|他的普通话很标准。|그의 표준어 발음은 아주 정확해요.
表||请填一下这张表。|이 표를 작성해 주세요.
表格|表(표) + 格(칸) → 칸이 있는 표|请把表格填好。|서식을 다 채워 주세요.
表示|表(드러내다) + 示(보이다) → 나타내다|他点头表示同意。|그는 고개를 끄덕여 동의를 나타냈어요.
表现|表(드러내다) + 现(나타내다) → 드러내다, 태도|他这次考试表现很好。|그는 이번 시험에서 잘했어요.
表扬|表(드러내다) + 扬(날리다) → 드러내어 높이다 = 칭찬하다|老师表扬了他。|선생님이 그를 칭찬했어요.
饼干|饼(떡) + 干(마르다) → 마른 떡 = 비스킷|孩子喜欢吃饼干。|아이는 과자를 좋아해요.
并||这个办法并不难。|이 방법은 결코 어렵지 않아요.
并且|并(아우르다) + 且(또) → 게다가|他会说汉语，并且说得很好。|그는 중국어를 할 줄 알고, 게다가 아주 잘해요.
播放|播(퍼뜨리다) + 放(놓다) → 방송하다, 재생하다|电视正在播放新闻。|텔레비전에서 뉴스를 방송하고 있어요.
博士|博(넓다) + 士(선비) → 학식이 넓은 선비 = 박사|她是一位博士。|그녀는 박사예요.
不必|不(아니다) + 必(반드시) → 반드시 그럴 필요 없다|你不必担心。|걱정할 필요 없어요.
不便|不(아니다) + 便(편하다) → 불편하다|没有车很不便。|차가 없으면 아주 불편해요.
不得不|不得(할 수 없다) + 不(아니다) → 안 할 수 없다 = 어쩔 수 없이 ~하다|下大雨了，我们不得不回家。|비가 많이 와서 어쩔 수 없이 집에 가야 했어요.
不断|不(아니다) + 断(끊다) → 끊이지 않다 = 끊임없이|他的汉语水平不断提高。|그의 중국어 실력은 끊임없이 좋아져요.
不够|不(아니다) + 够(충분하다) → 부족하다|我的钱不够。|돈이 모자라요.
不管|不(아니다) + 管(상관하다) → 상관하지 않고 = ~에 관계없이|不管多忙，他每天都运动。|아무리 바빠도 그는 매일 운동해요.
不光|不(아니다) + 光(오직) → 오직 ~만이 아니라|不光我，大家都喜欢他。|나뿐만 아니라 모두가 그를 좋아해요.
不过|不(아니다) + 过(지나치다) → 지나치지 않다 = 그런데, 다만|这件衣服很好看，不过有点儿贵。|이 옷 예쁜데, 좀 비싸요.
不仅|不(아니다) + 仅(겨우) → ~일 뿐만 아니라|她不仅会唱歌，还会跳舞。|그녀는 노래뿐 아니라 춤도 춰요.
不论|不(아니다) + 论(따지다) → 따지지 않고 = ~을 막론하고|不论遇到什么困难，我都不放弃。|어떤 어려움이 있어도 포기하지 않아요.
不满|不(아니다) + 满(차다) → 차지 않다 = 불만스럽다|他对这个结果很不满。|그는 이 결과에 아주 불만이에요.
不如|不(아니다) + 如(같다) → 같지 못하다 = ~만 못하다|坐车不如走路快。|차 타는 게 걷는 것보다 빠르지 않아요.
步||往前走两步。|앞으로 두 걸음 가세요.
部||这部电影很好看。|이 영화는 아주 재미있어요.
部分|部(부분) + 分(나누다) → 나눈 부분|这本书的第一部分很有意思。|이 책의 첫 부분이 아주 재미있어요.
部门|部(부) + 门(문, 분야) → 부서|你在哪个部门工作？|어느 부서에서 일해요?
擦||请把桌子擦干净。|탁자를 깨끗하게 닦아 주세요.
猜||你猜我今年几岁？|내가 올해 몇 살인지 맞혀 봐요.
材料|材(재목) + 料(재료) → 재료, 자료|做这个菜需要什么材料？|이 요리 하려면 무슨 재료가 필요해요?
参观|参(참여하다) + 观(보다) → 참관하다, 견학하다|我们明天去参观博物馆。|내일 박물관을 견학해요.
参赛|参(참가하다) + 赛(경기) → 경기에 참가하다|这次有一百多人参赛。|이번에 백여 명이 경기에 참가해요.
餐厅|餐(식사) + 厅(홀) → 식사하는 홀 = 식당|学校的餐厅在二楼。|학교 식당은 2층에 있어요.
操场|操(체조) + 场(마당) → 체조하는 마당 = 운동장|学生们在操场上跑步。|학생들이 운동장에서 달리고 있어요.
厕所|厕(뒷간) + 所(곳) → 화장실|厕所在哪里？|화장실이 어디예요?
查看|查(조사하다) + 看(보다) → 살펴보다|请查看一下你的邮箱。|메일함 좀 확인해 보세요.
查找|查(조사하다) + 找(찾다) → 찾아보다|我在网上查找资料。|인터넷에서 자료를 찾아요.
茶叶|茶(차) + 叶(잎) → 찻잎|这是我从杭州买的茶叶。|이건 항저우에서 산 찻잎이에요.
差点儿|差(모자라다) + 点儿(조금) → 조금 모자라서 = 하마터면|我差点儿忘了。|하마터면 잊을 뻔했어요.
产生|产(낳다) + 生(생기다) → 생기다|他对汉语产生了兴趣。|그는 중국어에 흥미가 생겼어요.
厂||他在一家汽车厂工作。|그는 자동차 공장에서 일해요.
场||昨天下了一场大雨。|어제 큰비가 한바탕 내렸어요.
超过|超(뛰어넘다) + 过(지나다) → 초과하다|这里的温度超过了三十度。|여기 기온이 30도를 넘었어요.
车速|车(차) + 速(속도) → 차량 속도|这条路上车速不能太快。|이 길에서는 차 속도를 너무 내면 안 돼요.
车位|车(차) + 位(자리) → 차 자리 = 주차 공간|这里没有车位了。|여기는 주차 자리가 없어요.
成功|成(이루다) + 功(공) → 공을 이루다 = 성공|祝你成功！|성공을 빌어요!
成为|成(이루다) + 为(되다) → ~이 되다|他成为了一名医生。|그는 의사가 되었어요.
诚实|诚(정성) + 实(참) → 정직하다|他是一个诚实的人。|그는 정직한 사람이에요.
城||这座城有很长的历史。|이 성은 역사가 아주 길어요.
乘||五乘二等于十。|5 곱하기 2는 10이에요.
乘客|乘(타다) + 客(손님) → 타는 손님 = 승객|飞机上有两百多名乘客。|비행기에 승객이 이백여 명 있어요.
乘坐|乘(타다) + 坐(타다, 앉다) → 타다|欢迎乘坐本次航班。|이번 항공편에 탑승하신 것을 환영합니다.
吃惊|吃(받다, 당하다) + 惊(놀람) → 놀람을 당하다 = 놀라다|听到这个消息，大家都很吃惊。|이 소식을 듣고 모두 놀랐어요.
迟||对不起，我来迟了。|미안해요, 늦었어요.
出差|出(나가다) + 差(파견된 일) → 일로 나가다 = 출장 가다|爸爸下周去上海出差。|아빠는 다음 주에 상하이로 출장 가요.
出口|出(나가다) + 口(입구) → 나가는 곳 = 출구, 수출|地铁站的出口在哪儿？|지하철역 출구가 어디예요?
出现|出(나오다) + 现(나타나다) → 나타나다|他突然出现在我面前。|그가 갑자기 내 앞에 나타났어요.
出行|出(나가다) + 行(다니다) → 길을 나서다|下雪天出行要注意安全。|눈 오는 날 외출할 때는 안전에 주의하세요.
出租|出(내놓다) + 租(세) → 세를 놓다|这套房子出租。|이 집은 세를 놓아요.
厨房|厨(부엌) + 房(방) → 부엌|妈妈在厨房做饭。|엄마는 부엌에서 밥을 하고 있어요.
厨师|厨(부엌) + 师(전문가) → 요리사|他是一名厨师。|그는 요리사예요.
窗户|窗(창) + 户(문) → 창문|请把窗户打开。|창문 좀 열어 주세요.
吹||今天风吹得很大。|오늘 바람이 세게 불어요.
词语|词(단어) + 语(말) → 어휘|请用这些词语写一段话。|이 단어들로 글을 한 단락 써 보세요.
此||此处不能停车。|이곳은 주차할 수 없습니다.
此次|此(이) + 次(번) → 이번|此次会议很重要。|이번 회의는 아주 중요해요.
此外|此(이) + 外(밖) → 이 밖에|此外，我还想说一件事。|그 밖에 한 가지 더 말하고 싶어요.
从此|从(~부터) + 此(이) → 이때부터|从此，他每天都去跑步。|그 후로 그는 매일 달리러 가요.
从来|从(~부터) + 来(지금까지) → 지금까지, 여태|我从来没去过上海。|나는 지금까지 상하이에 가 본 적이 없어요.
从中|从(~부터) + 中(가운데) → 그 가운데서|我从中学到了很多。|그 가운데서 많은 걸 배웠어요.
粗||这棵树很粗。|이 나무는 아주 굵어요.
粗心|粗(거칠다) + 心(마음) → 마음이 거칠다 = 덤벙대다|你太粗心了，又写错了。|너무 덤벙대네요, 또 잘못 썼어요.
村||他住在一个小村里。|그는 작은 마을에 살아요.
存||我把钱存在银行里。|돈을 은행에 저금해요.
错过|错(어긋나다) + 过(지나다) → 어긋나 지나치다 = 놓치다|我错过了最后一班车。|막차를 놓쳤어요.
错误|错(틀리다) + 误(그르치다) → 잘못|这是我的错误。|이건 제 잘못이에요.
达到|达(이르다) + 到(이르다) → 도달하다|他的汉语已经达到了很高的水平。|그의 중국어는 이미 높은 수준에 이르렀어요.
答||请答一下这个问题。|이 질문에 대답해 주세요.
答案|答(대답) + 案(안건) → 대답의 안 = 답안|这个问题的答案是什么？|이 문제의 답이 뭐예요?
答应|答(대답하다) + 应(응하다) → 승낙하다|他答应明天来帮我。|그는 내일 도와주러 오겠다고 했어요.
打败|打(치다) + 败(지다) → 쳐서 지게 하다 = 물리치다|我们打败了对手。|우리는 상대를 이겼어요.
打工|打(하다) + 工(일) → 일을 하다 = 아르바이트하다|周末我在咖啡店打工。|주말에 카페에서 아르바이트해요.
打扰|打(하다) + 扰(어지럽히다) → 방해하다|对不起，打扰一下。|실례지만, 잠깐만요.
打印|打(치다) + 印(찍다) → 인쇄하다|请帮我打印一下这个文件。|이 파일 좀 인쇄해 주세요.
