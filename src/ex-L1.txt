# 단어|왜 이 한자들인지|예문|예문 번역
爱||我爱我的家人。|나는 우리 가족을 사랑해요.
八||我早上八点起床。|나는 아침 8시에 일어나요.
爸爸|爸(아버지)를 두 번 불러 친근하게 → 아빠|我爸爸是老师。|우리 아빠는 선생님이에요.
吧||我们走吧。|우리 가자.
白天|白(희다, 밝다) + 天(날) → 밝은 날 = 낮|他白天工作，晚上学习。|그는 낮에 일하고 밤에 공부해요.
百||这本书一百块。|이 책은 100위안이에요.
半||我等了半个小时。|나는 30분(반 시간) 기다렸어요.
包子|包(싸다) + 子(명사 꼬리) → 소를 싸서 찐 것 = 찐빵|早上我吃了两个包子。|아침에 바오쯔 두 개를 먹었어요.
杯子|杯(잔) + 子(명사 꼬리) → 컵|这个杯子是我的。|이 컵은 내 거예요.
本||我买了三本书。|나는 책 세 권을 샀어요.
边||学校在医院东边。|학교는 병원 동쪽에 있어요.
便宜|便(편하다) + 宜(알맞다) → 부담 없이 알맞다 = 값이 싸다|这件衣服很便宜。|이 옷은 아주 싸요.
病||他病了，今天没来。|그는 아파서 오늘 안 왔어요.
不||我不喝咖啡。|나는 커피를 안 마셔요.
不客气|不(아니다) + 客气(사양하다, 예의 차리다) → 사양하지 마세요 = 천만에요|“谢谢你！”“不客气。”|"고마워요!" "천만에요."
不要|不(아니다) + 要(하려 하다) → 하려 하지 마 = ~하지 마라|上课的时候不要说话。|수업 시간에는 떠들지 마세요.
菜||妈妈做的菜很好吃。|엄마가 만든 요리는 아주 맛있어요.
茶||你喝茶吗？|차 마실래요?
唱||她很喜欢唱歌。|그녀는 노래하는 걸 아주 좋아해요.
超市|超(뛰어넘다) + 市(시장) → 보통 시장을 넘어선 큰 가게 = 슈퍼마켓|我去超市买水果。|나는 슈퍼에 과일 사러 가요.
车||这是你的车吗？|이게 당신 차예요?
吃||你吃饭了吗？|밥 먹었어요?
出租车|出租(세를 놓다) + 车(차) → 돈 받고 빌려주는 차 = 택시|我们坐出租车去吧。|우리 택시 타고 가자.
穿||今天很冷，你多穿点儿衣服。|오늘 추우니까 옷 좀 더 입어요.
打电话|打(치다, 걸다) + 电话(전화) → 전화를 걸다|晚上我给妈妈打电话。|저녁에 엄마에게 전화해요.
大||他的家很大。|그의 집은 아주 커요.
大家|大(크다, 모두) + 家(집) → 온 집안 사람 = 모두, 여러분|大家好！|여러분 안녕하세요!
大学|大(큰) + 学(배움) → 큰 배움의 곳 = 대학|我哥哥在北京上大学。|우리 형은 베이징에서 대학에 다녀요.
大学生|大学(대학) + 生(학생) → 대학생|她是大学生。|그녀는 대학생이에요.
到||我到学校了。|나 학교에 도착했어.
的||这是我的书。|이건 내 책이에요.
弟弟|弟(아우)를 두 번 불러 친근하게 → 남동생|我弟弟今年八岁。|내 남동생은 올해 여덟 살이에요.
第||这是我第一次来中国。|이번이 중국에 처음 온 거예요.
点||现在几点？|지금 몇 시예요?
电话|电(전기) + 话(말) → 전기로 하는 말 = 전화|你的电话号是多少？|전화번호가 몇 번이에요?
电脑|电(전기) + 脑(뇌) → 전기로 움직이는 뇌 = 컴퓨터|我用电脑学习汉语。|나는 컴퓨터로 중국어를 공부해요.
电视|电(전기) + 视(보다) → 전기로 보는 것 = 텔레비전|爸爸在看电视。|아빠는 텔레비전을 보고 있어요.
电影|电(전기) + 影(그림자) → 전기로 비추는 그림자 = 영화|我们去看电影吧。|우리 영화 보러 가자.
电影院|电影(영화) + 院(집, 기관) → 영화관|电影院在商店旁边。|영화관은 상점 옆에 있어요.
店||这家店的包子很好吃。|이 가게 바오쯔는 아주 맛있어요.
东西|东(동쪽) + 西(서쪽) → 동서 사방에서 오는 것 = 물건|我去商店买东西。|나는 물건 사러 상점에 가요.
都||我们都是学生。|우리는 모두 학생이에요.
读||请读一下这个字。|이 글자 좀 읽어 주세요.
读书|读(읽다) + 书(책) → 책을 읽다 = 공부하다|他喜欢读书。|그는 책 읽는 걸 좋아해요.
对||你说得对。|당신 말이 맞아요.
对不起|对(마주하다) + 不起(감당하지 못하다) → 당신을 마주할 면목이 없다 = 미안합니다|对不起，我来晚了。|미안해요, 늦었어요.
多||这里人很多。|여기는 사람이 많아요.
多少|多(많다) + 少(적다) → 많은지 적은지 = 얼마|这个多少钱？|이거 얼마예요?
儿子|儿(아이) + 子(아들) → 아들|他有一个儿子。|그는 아들이 하나 있어요.
二||我有二十块钱。|나는 20위안이 있어요.
饭||我们一起吃饭吧。|우리 같이 밥 먹자.
饭店|饭(밥) + 店(가게) → 밥을 파는 큰 가게 = 식당, 호텔|我们住在这家饭店。|우리는 이 호텔에 묵어요.
房间|房(방) + 间(칸) → 방|我的房间不大。|내 방은 크지 않아요.
飞机|飞(날다) + 机(기계) → 나는 기계 = 비행기|我坐飞机去上海。|나는 비행기 타고 상하이에 가요.
非常|非(아니다) + 常(보통) → 보통이 아니다 = 매우|今天非常热。|오늘은 매우 더워요.
分||现在八点十分。|지금 8시 10분이에요.
分钟|分(분) + 钟(시각) → 분 (시간 길이)|我走路十分钟就到。|걸어서 10분이면 도착해요.
高兴|高(높다) + 兴(흥) → 흥이 높다 = 기쁘다|认识你很高兴。|만나서 반가워요.
哥哥|哥(형)를 두 번 불러 친근하게 → 형, 오빠|我哥哥很高。|우리 형은 키가 커요.
歌||这首歌很好听。|이 노래 정말 좋아요.
个||我有一个妹妹。|나는 여동생이 한 명 있어요.
给||我给你一本书。|너에게 책 한 권 줄게.
工作|工(일) + 作(하다) → 일을 하다 = 일, 일하다|你在哪儿工作？|어디에서 일해요?
公司|公(공공) + 司(맡다) → 일을 맡아 하는 조직 = 회사|我在一家公司工作。|나는 한 회사에서 일해요.
狗||我家有一只小狗。|우리 집에는 강아지가 한 마리 있어요.
贵||这个手机太贵了。|이 휴대폰은 너무 비싸요.
国||你是哪国人？|어느 나라 사람이에요?
还||他还没来。|그는 아직 안 왔어요.
孩子|孩(아이) + 子(아이) → 아이|孩子们在外边玩儿。|아이들이 밖에서 놀고 있어요.
汉语|汉(한족) + 语(말) → 한족의 말 = 중국어|我在学习汉语。|나는 중국어를 공부하고 있어요.
汉字|汉(한족) + 字(글자) → 한족의 글자 = 한자|汉字很有意思。|한자는 정말 재미있어요.
好||今天天气很好。|오늘 날씨가 좋아요.
好吃|好(좋다) + 吃(먹다) → 먹기 좋다 = 맛있다|这个菜很好吃。|이 요리 정말 맛있어요.
好看|好(좋다) + 看(보다) → 보기 좋다 = 예쁘다, 재미있다|这个电影很好看。|이 영화 정말 재미있어요.
好听|好(좋다) + 听(듣다) → 듣기 좋다|她的声音很好听。|그녀의 목소리는 듣기 좋아요.
好玩儿|好(좋다) + 玩儿(놀다) → 놀기 좋다 = 재미있다|北京很好玩儿。|베이징은 정말 재미있어요.
号||今天几月几号？|오늘 몇 월 며칠이에요?
喝||我想喝水。|물 마시고 싶어요.
和||我和朋友去看电影。|나는 친구와 영화 보러 가요.
很||我很好。|나는 아주 잘 지내요.
后||吃饭后我们去玩儿。|밥 먹은 후에 우리 놀러 가요.
回||我明天回家。|나는 내일 집에 돌아가요.
会||你会说汉语吗？|중국어 할 줄 알아요?
火车|火(불) + 车(차) → 불(석탄)의 힘으로 달리는 차 = 기차|我们坐火车去北京。|우리는 기차 타고 베이징에 가요.
鸡蛋|鸡(닭) + 蛋(알) → 달걀|我早上吃了一个鸡蛋。|아침에 달걀 하나 먹었어요.
几||你家有几口人？|가족이 몇 명이에요?
家||我家在北京。|우리 집은 베이징에 있어요.
家人|家(집) + 人(사람) → 집안 사람 = 가족|我很想我的家人。|가족이 정말 보고 싶어요.
见||明天见！|내일 봐요!
件||这件衣服很漂亮。|이 옷 정말 예뻐요.
饺子|饺(교자) + 子(명사 꼬리) → 만두|我们一起包饺子吧。|우리 같이 만두 빚자.
叫||你叫什么名字？|이름이 뭐예요?
姐姐|姐(누이)를 두 번 불러 친근하게 → 누나, 언니|我姐姐在医院工作。|우리 언니는 병원에서 일해요.
今年|今(지금) + 年(해) → 지금의 해 = 올해|我今年二十岁。|나는 올해 스무 살이에요.
今天|今(지금) + 天(날) → 지금의 날 = 오늘|今天星期几？|오늘 무슨 요일이에요?
九||我九点上课。|나는 9시에 수업이 있어요.
觉得|觉(느끼다) + 得(얻다) → 느껴서 얻다 = ~라고 생각하다|我觉得汉语不难。|나는 중국어가 어렵지 않다고 생각해요.
开||请开门。|문 좀 열어 주세요.
开车|开(몰다) + 车(차) → 차를 몰다 = 운전하다|爸爸开车去公司。|아빠는 차를 운전해서 회사에 가요.
看||我在看书。|나는 책을 보고 있어요.
看病|看(보다) + 病(병) → 병을 보다 = 진찰받다|我下午去医院看病。|오후에 병원에 진찰받으러 가요.
看见|看(보다) + 见(보이다) → 보아서 눈에 들어오다 = 보이다|我看见他了。|그 사람을 봤어요.
可以|可(가능하다) + 以(~로써) → 그렇게 할 수 있다 = ~해도 된다|我可以坐这儿吗？|여기 앉아도 돼요?
课||今天有汉语课。|오늘 중국어 수업이 있어요.
口||我家有四口人。|우리 가족은 네 명이에요.
块||一杯茶十块。|차 한 잔에 10위안이에요.
来||你什么时候来？|언제 와요?

了||我吃饭了。|나 밥 먹었어.
冷||今天很冷。|오늘 추워요.
里||书在包里。|책은 가방 안에 있어요.

零||我的电话号是零一二……|제 전화번호는 012……예요.
六||我六岁的时候在北京。|나는 여섯 살 때 베이징에 있었어요.
妈妈|妈(어머니)를 두 번 불러 친근하게 → 엄마|妈妈在做饭。|엄마는 밥을 하고 있어요.
吗||你是中国人吗？|중국 사람이에요?

忙||你最近忙吗？|요즘 바빠요?

没关系|没(없다) + 关系(관계) → 상관없다 = 괜찮아요|“对不起！”“没关系。”|"미안해요!" "괜찮아요."

妹妹|妹(누이동생)를 두 번 불러 친근하게 → 여동생|我妹妹很漂亮。|내 여동생은 아주 예뻐요.

米饭|米(쌀) + 饭(밥) → 쌀밥|我要一碗米饭。|밥 한 공기 주세요.
