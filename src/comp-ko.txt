# 구성 요소(부수·부품)|유래|외우는 법
爫|새의 발톱(손톱)이 아래로 향한 모양. 爪가 글자 위에 붙을 때의 모양.|글자 맨 위의 爫는 ‘위에서 내려 잡는 손’. 爱·采·受에서 손이 무언가를 잡는 장면을 떠올려요.
冖|천을 덮어씌운 모양.|지붕(宀)에서 꼭지 점을 뗀 모양 = 그냥 덮개. 学·写·军에서 ‘덮인 공간’.
丷|여덟 팔(八)이 위에 작게 붙은 모양.|두 점이 갈라짐 = 나뉨·뿔·김. 半·关·兑 위에 달린 작은 두 점.
勹|사람이 몸을 구부려 무언가를 감싸는 모양.|팔로 껴안듯 둘러싼 모양 = 싸다. 包·句·勺·匀은 모두 ‘감싸고 있는’ 글자.
巳|몸을 웅크린 뱀(태아)의 모양.|己(완전 열림)·已(살짝 열림)·巳(꽉 닫힘). 包 속에서 포대기에 싸인 아기.
辶|길을 걸어가는 발의 모양 (책받침).|글자 왼쪽 아래를 받치는 ‘길’. 辶가 있으면 가다·오다·멀다·가깝다 등 이동과 관련: 进·过·远·近·道.
亻|사람(人)이 왼쪽에 설 때 줄어든 모양.|사람인변. 亻가 있으면 사람의 행동·상태: 你·他·住·休·做.
宀|지붕이 있는 집 모양 (갓머리).|꼭지 점이 있는 지붕 = 집. 家·安·室·宿·客은 모두 집 안의 일.
疒|사람이 병상에 기대 누운 모양 (병질엄).|침대에 누운 환자. 疒가 있으면 병·아픔: 病·疼·痛·瘦·疯.
丙|제사상(또는 물고기 꼬리) 모양을 빌려 천간 ‘병’으로 썼다.|病의 소리(bìng) 담당. 병상(疒)에 丙 = 병(bìng)!
覀|덮개가 씌워진 모양 (西의 변형).|위를 덮는 뚜껑. 要·票에서 ‘위를 덮은 것’.
艹|풀 두 포기가 돋아난 모양 (초두머리).|글자 머리의 풀 = 식물. 艹가 있으면 풀·꽃·채소·약: 花·草·菜·茶·药.
昌|해(日)가 뜬 낮에 말(曰)함 → 밝게 번창하다.|해가 둘 겹쳐 쨍쨍 = 창성함. 唱(chàng)의 소리 담당: 입(口)으로 밝게(昌) 노래!
亠|머리·지붕 꼭대기를 나타내는 모양 (돼지해머리).|글자 맨 위 뚜껑. 京·高·亮·六에서 ‘높은 지붕’.
乞|구름 기운(气)에서 한 획을 뺀 모양을 빌려 ‘빌다’로 씀.|气에서 획이 빠져 기운이 없다 → 구걸하다. 吃(chī)의 소리 담당.
凵|위가 터진 그릇(움푹한 곳) 모양.|위가 열린 상자. 出·画·凶에서 ‘움푹 패인 곳’.
屮|땅을 뚫고 나온 풀 싹 모양.|한 포기 새싹. 出의 위쪽 = 싹이 돋아 나간다.
禾|이삭이 고개 숙인 벼 모양.|木 위에 이삭(丿) = 벼. 禾가 있으면 곡식·수확·세금: 种·秋·租·税·积.
穴|동굴 입구 모양.|지붕(宀) 아래 八 = 굴. 穴이 있으면 구멍·빈 공간: 空·窗·穿·究·窄.
扌|손(手)이 왼쪽에 설 때 줄어든 모양 (재방변).|손 수 변. 扌가 있으면 손으로 하는 동작: 打·拿·找·推·拉.
丁|못을 위에서 본 모양.|못 하나 = 단단히 박다. 打(dǎ)·灯·订·厅의 소리 담당(ding 계열).
曰|입(口)에서 말(一)이 나오는 모양.|日보다 납작한 입 = 말하다. 書·曹·冒의 일부.
乚|굽은 갈고리 모양.|꺾어 올리는 획. 礼·乱·也의 끝 갈고리.
讠|말씀 언(言)이 왼쪽에 설 때 줄어든 모양.|말씀언변. 讠가 있으면 말·언어: 说·话·语·请·谢·认.
舌|입(口)에서 혀(千)가 나온 모양.|입 밖으로 내민 혀. 话·活·适·甜에 들어가고, 刮(guā)·括 등의 소리도 냄.
豕|옆으로 선 돼지 모양.|배 불룩한 돼지. 家 = 지붕 아래 돼지. 象·逐에도 짐승 모양.
⺍|작을 소(小)가 위에 붙은 모양.|반짝이는 세 점 = 빛·작은 것. 学·觉·当 위의 세 점.
刂|칼(刀)이 오른쪽에 설 때 세운 모양 (선칼도방).|칼 두 획. 刂가 있으면 자르다·나누다: 别·到·刻·剪·判.
弓|활을 세워 놓은 모양.|굽은 활. 张·弹·强·引은 모두 활을 당기는 동작.
⺮|대나무 두 줄기 모양 (竹이 위에 붙은 모양).|대죽머리. ⺮가 있으면 대나무로 만든 것: 笔·筷·篮·箱·简.
灬|불(火)이 아래에 붙을 때 네 점으로 바뀐 모양 (연화발).|아래 네 점 = 활활 타는 불. 灬가 있으면 불·열: 热·点·照·熟·煮·熬.
⺼|고기(肉)가 왼쪽에 설 때 月처럼 바뀐 모양 (육달월).|月처럼 생겼지만 ‘몸’. 脸·脚·脑·胖·肚는 모두 몸의 일부.
礻|제단(示)이 왼쪽에 설 때 줄어든 모양.|보일시변. 礻가 있으면 신·제사·복: 礼·福·神·祝·社.
彡|가지런히 늘어진 털·빛줄기 모양.|세 줄 = 무늬·빛·털. 影·彩·须·形에서 반짝이는 줄무늬.
阝|언덕(왼쪽)·고을(오른쪽)을 나타내는 모양.|왼쪽 阝 = 언덕(院·阴·陆), 오른쪽 阝 = 마을(都·部·那).
兀|사람(儿) 위를 一로 잘라 우뚝 선 모양.|머리 없는 사람처럼 뭉툭하게 우뚝. 光·元과 비슷한 모양.
囗|사방을 둘러싼 울타리 모양 (큰입구몸).|口보다 큰 네모 = 둘러싸다. 国·园·围·回·因.
丨|위아래로 꿰뚫는 막대.|세로 한 획 = 꿰뚫다. 中의 가운데 막대.
寸|손목 아래 맥을 짚는 자리(、)를 표시한 손.|손 + 점 = 한 치, 손. 寸이 있으면 손으로 하는 일: 对·付·射·封·导.
丿|오른쪽 위에서 왼쪽 아래로 삐친 획.|삐침 한 획. 千·失·乐 등의 첫 획.
饣|밥 식(食)이 왼쪽에 설 때 줄어든 모양.|밥식변. 饣가 있으면 먹을 것: 饭·饺·饿·饱·饮.
尚|집(冂) 위로 김(⺌)이 오르는 모양 → 높이다.|위로 솟는 연기 = 높이 받들다. 常·尝·堂·躺·趟(tang/chang 계열)의 소리 담당.
钅|쇠 금(金)이 왼쪽에 설 때 줄어든 모양.|쇠금변. 钅가 있으면 금속: 钱·铁·钟·锅·钥·镜.
冋|경계(冂) 안의 땅(口).|울타리 안 마당. 尚·向 속 모양.
纟|실 사(糸)가 왼쪽에 설 때 줄어든 모양.|실사변. 纟가 있으면 실·잇다·묶다: 给·红·经·结·组·绿.
丄|一 위에 한 획을 세워 ‘위’를 나타낸 옛 글자.|上의 옛 모양. 땅 위로 선 막대.
乍|칼로 갑자기 자르는 모양을 빌려 ‘잠깐, 갑자기’.|乍가 들어가면 zuo/zen/zha 소리: 作·昨·怎·炸·窄.
厶|누에고치 모양 → 사사로이 자기 것.|동그랗게 웅크린 나. 私 = 내 벼(禾). 去·云·台에도 들어 있음.
犭|개(犬)가 왼쪽에 설 때 바뀐 모양 (개사슴록변).|큰개견변. 犭가 있으면 짐승: 狗·猫·猴·猪·狂.
亥|돼지 모양을 빌려 12지의 ‘해’.|亥 = hai/gai/ke 소리: 孩·该·刻·咳.
氵|물(水)이 왼쪽에 설 때 세 점이 된 모양 (삼수변).|세 방울 = 물. 氵가 있으면 물·액체·강: 河·海·洗·游·酒.
吾|다섯(五) 입(口) → 나.|‘나’의 말 = 语(yǔ)의 소리 담당.
王|원래 구슬 꿰미(玉) 모양. 글자 왼쪽에서는 ‘구슬 옥’ 뜻.|왼쪽 王 = 구슬. 玩·球·环·理·现은 구슬과 관련.
丂|막힌 숨이 나오려는 모양.|굽은 획 = kao/hao/qiao 소리: 考·号·巧.
曷|해(日) 아래 사람이 무엇을 구하는 모양 → 어찌.|曷 = he/ke 소리: 喝(hē)·渴(kě). 입·물이 붙으면 마시기!
彳|길을 조금 걷는 발걸음 (두인변).|사람인변(亻)에 한 획 더 = 길·걷기: 往·很·待·律·街.
艮|눈을 부릅뜨고 뒤돌아 멈춘 사람 → 그치다.|艮 = gen/hen/yin 소리: 跟·很·根·眼·银·限.
疋|무릎과 발 모양 → 발.|발 모양. 是·楚·疑·旋에서 걷는 발.
丩|넝쿨이 서로 얽힌 모양.|두 줄이 얽힘 = jiu 소리: 叫(jiào)·收.
廾|두 손을 맞잡아 받드는 모양.|두 손(十十) = 받들다. 开·弄·弃·算에서 두 손.
冂|멀리 있는 경계(성곽) 모양.|위가 막힌 테두리. 同·内·网·周의 바깥틀.
夬|활시위를 손가락으로 터서 튕기는 모양.|夬 = kuai/jue/que 소리: 快·块·决·缺.
耂|늙을 로(老)의 윗부분.|허리 굽은 노인의 머리. 考·孝·者.
匕|숟가락(또는 몸을 굽힌 사람) 모양.|숟가락 = 비수. 比·北·化·此·匙.
帀|빙 둘러 감싼 모양.|두르다. 师의 오른쪽.
亅|아래 끝이 휜 갈고리.|갈고리 한 획. 了·事·小의 세로 갈고리.
乛|꺾어 내린 획.|가로로 갔다 꺾이는 획. 买·习의 첫 획.
冫|얼음이 언 결(두 점) 모양 (이수변).|두 방울 = 얼음. 冫가 있으면 차가움: 冷·冰·凉·冻·准.
田|논밭을 사방으로 나눈 모양.|밭 = 땅·농사. 男 = 밭에서 힘쓰는 사람. 界·思·留·累.
忄|마음 심(心)이 왼쪽에 설 때 세운 모양 (심방변).|세운 마음. 忄가 있으면 감정: 怕·快·忙·情·懂·慢.
亡|사람이 숨어 사라진 모양 → 망하다, 없다.|亡 = wang/mang 소리: 忘(wàng)·忙(máng)·望. 마음(心)이 사라지면 잊는다(忘)!
苗|밭(田)에 돋은 풀(艹) = 모.|논밭의 새싹. 猫(māo)·描(miáo)의 소리 담당 — 고양이 울음 ‘먀오’.
糸|꼬인 실타래 모양.|실 사. 아래에 오면 그대로: 系·紧·累·紫·素.
ナ|왼손(또는 손) 모양.|손. 有 = 손(ナ)에 고기(月), 友 = 손과 손.
夂|뒤에서 천천히 따라오는 발 모양.|아래로 향한 발 = 가다·오다. 各·冬·条·夏·处.
尼|두 사람이 가까이 붙은 모양.|尼 = ni 소리: 呢(ne)·泥.
乃|아이를 밴 여인(또는 굽은 줄)의 모양을 빌려 ‘이에’.|乃 = nai/reng 소리: 奶(nǎi)·扔·仍. 여자(女)+乃 = 젖(奶)!
䒑|풀(艹)의 변형.|머리의 작은 풀. 前의 윗부분.
戋|창(戈)을 겹쳐 잘게 부수는 모양 → 작다, 해치다.|戋 = jian/qian 소리, ‘작고 얇음’: 钱·线·浅·践.
冏|창문이 밝게 빛나는 모양.|밝은 창. 商 안에 들어 있음.
彐|손(또는 돼지머리) 모양 (튼가로왈).|옆으로 누운 손 = 잡다. 雪·寻·当·灵·妇.
隹|꽁지가 짧은 새 모양.|새 추. 隹 = zhui/shui/tui 소리: 谁·推·准·堆·维. 集 = 나무 위 새들.
垂|가지가 늘어진 나무 모양.|축 늘어짐. 睡 = 눈(目)꺼풀이 축 늘어지면(垂) 잠!
兑|사람(兄)이 입을 벌려 웃는 모양 → 바꾸다, 기쁘다.|兑 = shui/tuo/yue 소리: 说·脱·税·阅.
丶|불꽃·점 모양.|점 하나. 主의 불꽃, 太의 점.
卜|거북 등딱지의 갈라진 금 모양 → 점.|점괘 금. 外·占·补(bǔ)·卡.
畏|무서운 얼굴(田)의 귀신이 몽둥이를 든 모양 → 두렵다.|무서운 탈. 喂(wèi)의 소리 담당.
戈|날이 달린 창 모양.|창 과. 我·找·战·或·戏 — 모두 창이 들어 있다.
壴|받침대 위에 놓인 북 모양.|세운 북. 鼓 = 북(壴)을 막대(支)로 친다, 喜 = 북 치고 노래.
射|활(身)을 손(寸)으로 당겨 쏘는 모양.|쏘다. 谢(xiè)의 소리 담당: 말(讠)을 쏘듯 ‘고마워!’
匸|무언가를 숨겨 두는 상자 모양.|감추는 상자. 医·区 바깥틀.
匚|물건을 넣는 네모난 상자 모양 (트인입구).|한쪽이 열린 상자. 医 = 상자에 화살.
矢|화살 모양.|화살 시. 知·短·矮·疑·医. 화살처럼 빠르다(知 = 빨리 안다).
冉|수염이 늘어진 모양.|천천히 늘어진 수염. 再와 모양이 닮았다.
乂|가위로 풀을 베는 모양 (X).|X자 = 베다·엇갈리다. 文·义·区·网 속의 X.
⺈|사람(人)이 위에서 구부러진 모양.|위에 쓴 작은 사람. 色·负·争·危·鱼 머리.
邦|풀 무성한(丰) 고을(阝) → 나라.|帮(bāng)의 소리 담당: 나라(邦)의 깃발(巾)로 돕다.
昔|햇볕(日)에 고기를 말리던 옛날 → 옛.|昔 = xi/jie/cuo 소리: 借·惜·错·措.
寺|손(寸)으로 땅(土)을 다스리는 관청 → 절.|寺 = shi/chi/te/deng 소리: 诗·时·持·特·等·待.
董|풀(艹)과 무거움(重) → 감독하다.|懂(dǒng)의 소리 담당: 마음(忄)으로 감독하듯(董) 안다.
官|지붕(宀) 아래 많은 관리가 모인 관청.|관청 관. 管·馆(guǎn)의 소리 담당.
斥|도끼(斤)에 점을 더해 내리쳐 물리침.|斥 = chai/su 소리: 拆·诉.
勿|깃발이 펄럭이는 모양을 빌려 ‘~하지 마라’.|勿 = wu/hu 소리: 物·忽. ‘아니다’ 뜻.

奂|사람이 손으로 크게 펼쳐 빛나는 모양.|빛나다. 换(huàn)의 소리 담당.

妾|죄인 낙인(辛)이 찍힌 여자(女) → 첩.|接(jiē)의 소리 담당: 손(扌)으로 맞이하다.
吉|선비(士)의 말(口) → 좋다, 길하다.|좋은 말. 结(jié)의 소리 담당: 실(纟)로 좋게(吉) 맺다.

犬|옆으로 선 개 모양.|개 견. 哭·器·状·献·默·突에 개가 숨어 있음.
卯|문을 양쪽으로 연 모양 → 토끼(12지).|열린 두 문짝. 聊·留(liu/liao 소리).
乇|풀잎이 땅에 매달린 모양.|托(맡기다)의 원형.

奉|두 손으로 받들어 올리는 모양.|받들다. 棒(bàng)의 소리 담당.
