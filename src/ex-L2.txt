爱好|爱(사랑하다) + 好(좋아하다, hào) → 사랑하고 좋아하는 것 = 취미|你的爱好是什么？|취미가 뭐예요?
白色|白(희다) + 色(빛깔) → 흰색|我想买一件白色的衣服。|흰색 옷을 하나 사고 싶어요.
班||我们班有三十个学生。|우리 반에는 학생이 서른 명 있어요.
帮||你能帮我一下吗？|나 좀 도와줄 수 있어요?
帮忙|帮(돕다) + 忙(바쁨) → 바쁜 일을 돕다 = 도와주다|谢谢你帮忙！|도와줘서 고마워요!
包||我的包在哪儿？|내 가방 어디 있어요?
本子|本(책) + 子(명사 꼬리) → 공책|请把名字写在本子上。|이름을 공책에 써 주세요.
比||哥哥比我高。|형은 나보다 키가 커요.
笔||我可以用一下你的笔吗？|펜 좀 써도 될까요?
别||别说话，听老师说。|떠들지 말고 선생님 말씀 들어요.
不错|不(아니다) + 错(틀리다) → 틀리지 않다 = 괜찮다, 좋다|这家饭馆的菜不错。|이 식당 음식 괜찮아요.
不好意思|不(아니다) + 好意思(낯이 서다) → 낯이 서지 않다 = 미안하다, 쑥스럽다|不好意思，我来晚了。|죄송해요, 늦었어요.
车站|车(차) + 站(멈춰 서는 곳) → 정류장, 역|车站离这儿不远。|정류장은 여기서 멀지 않아요.
出||他刚出去。|그는 방금 나갔어요.
出国|出(나가다) + 国(나라) → 나라 밖으로 나가다 = 출국하다|她明年想出国学习。|그녀는 내년에 유학 가고 싶어 해요.
出来|出(나가다) + 来(오다, 이쪽으로) → 안에서 이쪽으로 나오다|你快出来吧！|빨리 나와!
出门|出(나가다) + 门(문) → 문밖으로 나가다 = 외출하다|下雨了，别出门了。|비 와요, 나가지 마세요.
出去|出(나가다) + 去(가다, 저쪽으로) → 안에서 저쪽으로 나가다|我们出去走走吧。|우리 나가서 좀 걷자.
床||我的床很舒服。|내 침대는 아주 편해요.
词||这个词是什么意思？|이 단어는 무슨 뜻이에요?
次||我去过两次北京。|베이징에 두 번 가 봤어요.
从||我从韩国来。|나는 한국에서 왔어요.
从小|从(~부터) + 小(어릴 때) → 어릴 때부터|他从小就喜欢足球。|그는 어릴 때부터 축구를 좋아했어요.
错||对不起，是我错了。|미안해요, 제가 틀렸어요.
打||他每天打篮球。|그는 매일 농구를 해요.
打车|打(잡다) + 车(차) → 차를 잡다 = 택시를 타다|太晚了，我们打车回家吧。|너무 늦었어요, 택시 타고 집에 가요.
打开|打(치다, 하다) + 开(열다) → 열다, 켜다|请打开窗户。|창문 좀 열어 주세요.
但||我想去，但没有时间。|가고 싶지만 시간이 없어요.
但是|但(다만) + 是(~이다) → 그러나|汉语很难，但是很有意思。|중국어는 어렵지만 아주 재미있어요.
地||他高兴地笑了。|그는 기쁘게 웃었어요.
地铁|地(땅) + 铁(쇠, 철도) → 땅속 철도 = 지하철|我每天坐地铁上班。|나는 매일 지하철로 출근해요.
得||他得了第一名。|그는 1등을 했어요.
等||请等一下。|잠깐만 기다려 주세요.
懂||你懂我的意思吗？|내 말 무슨 뜻인지 알겠어요?
动||别动！|움직이지 마!
饭馆|饭(밥) + 馆(집, 가게) → 밥집 = 식당|学校旁边有一个小饭馆。|학교 옆에 작은 식당이 있어요.
飞||鸟在天上飞。|새가 하늘을 날아요.
高||我哥哥很高。|우리 형은 키가 커요.
高中|高(높은) + 中(중학교) → 높은 단계의 중학교 = 고등학교|我妹妹是高中生。|내 여동생은 고등학생이에요.
告诉|告(알리다) + 诉(말하다) → 알려 주다|请告诉我你的电话号码。|전화번호를 알려 주세요.
个子|个(낱개, 몸집) + 子(명사 꼬리) → 키|他个子很高。|그는 키가 커요.
跟||我跟朋友一起去。|나는 친구와 함께 가요.
公交车|公(공공) + 交(오가다) + 车(차) → 모두가 타고 오가는 차 = 버스|我坐公交车去学校。|나는 버스 타고 학교에 가요.
过||你去过中国吗？|중국에 가 본 적 있어요?
过来|过(건너다) + 来(오다) → 건너오다 = 다가오다|你过来看看。|이리 와서 좀 봐요.
过年|过(보내다) + 年(설, 해) → 설을 보내다|过年的时候我们回老家。|설에는 우리 고향에 가요.
过去|过(지나다) + 去(가다) → 지나가다, 지나간 때 = 과거|过去的事就别想了。|지난 일은 생각하지 마요.
还是|还(여전히) + 是(~이다) → 그래도 역시 = 아니면, 여전히|你喝茶还是喝咖啡？|차 마실래요, 아니면 커피 마실래요?
黑色|黑(검다) + 色(빛깔) → 검은색|我喜欢黑色的车。|나는 검은색 차를 좋아해요.
红茶|红(붉다) + 茶(차) → 붉은빛 차 = 홍차|你喝红茶还是绿茶？|홍차 마실래요, 녹차 마실래요?
红色|红(붉다) + 色(빛깔) → 빨간색|中国人很喜欢红色。|중국 사람들은 빨간색을 아주 좋아해요.
后面|后(뒤) + 面(쪽) → 뒤쪽|学校后面有一个公园。|학교 뒤에 공원이 하나 있어요.
花||公园里的花很漂亮。|공원의 꽃이 아주 예뻐요.
画||她画画儿画得很好。|그녀는 그림을 잘 그려요.
坏||我的手机坏了。|내 휴대폰이 고장 났어요.
回来|回(돌아가다) + 来(오다) → 돌아오다|你什么时候回来？|언제 돌아와요?
回去|回(돌아가다) + 去(가다) → 돌아가다|太晚了，我要回去了。|너무 늦었어요, 돌아가야겠어요.
机场|机(비행기) + 场(마당) → 비행기 마당 = 공항|我去机场接朋友。|나는 친구 마중하러 공항에 가요.
机票|机(비행기) + 票(표) → 비행기표|我买了去上海的机票。|상하이행 비행기표를 샀어요.
记得|记(기억하다) + 得(얻다) → 기억해 두다|你还记得我吗？|아직 나 기억해요?
间||我家有三间房。|우리 집은 방이 세 칸이에요.
教||王老师教我们汉语。|왕 선생님은 우리에게 중국어를 가르쳐요.

介绍|介(사이에 끼다) + 绍(잇다) → 사이에서 이어 주다 = 소개하다|我来介绍一下，这是我朋友。|소개할게요, 이쪽은 제 친구예요.
近||我家离学校很近。|우리 집은 학교에서 아주 가까워요.
进||请进！|들어오세요!
进来|进(들어가다) + 来(오다) → 들어오다|外面很冷，快进来吧。|밖이 추우니 얼른 들어와요.
进去|进(들어가다) + 去(가다) → 들어가다|我们进去看看吧。|우리 들어가서 좀 봐요.
经常|经(늘 지나다) + 常(늘) → 자주|我经常去这家店。|나는 이 가게에 자주 가요.
酒店|酒(술) + 店(가게) → 술집에서 숙박업소로 = 호텔|我们住的酒店很大。|우리가 묵는 호텔은 아주 커요.
就||我马上就来。|곧 갈게요.
咖啡|咖(kā) + 啡(fēi) → 소리를 옮긴 외래어 = 커피|你要喝咖啡吗？|커피 마실래요?
开始|开(열다) + 始(처음) → 처음을 열다 = 시작하다|电影几点开始？|영화 몇 시에 시작해요?
开学|开(열다) + 学(학교) → 학교 문을 열다 = 개학하다|九月一号开学。|9월 1일에 개학해요.
考||你考得怎么样？|시험 잘 봤어요?
考试|考(시험하다) + 试(시험) → 시험|明天有汉语考试。|내일 중국어 시험이 있어요.
可能|可(~할 수 있다) + 能(능하다) → 그럴 수 있다 = 아마|他可能不来了。|그는 아마 안 올 거예요.
裤子|裤(바지) + 子(명사 꼬리) → 바지|这条裤子有点儿长。|이 바지는 좀 길어요.
快||他跑得很快。|그는 아주 빨리 달려요.
快乐|快(상쾌하다) + 乐(즐겁다) → 즐겁다|生日快乐！|생일 축하해요!

篮球|篮(바구니) + 球(공) → 바구니에 넣는 공 = 농구|我们下午去打篮球吧。|오후에 농구하러 가자.
累||我今天很累。|오늘 너무 피곤해요.
离||我家离公司很远。|우리 집은 회사에서 멀어요.
里面|里(안) + 面(쪽) → 안쪽|里面有人吗？|안에 누구 있어요?

路||这条路很长。|이 길은 아주 길어요.

绿茶|绿(푸르다) + 茶(차) → 녹차|我每天喝一杯绿茶。|나는 매일 녹차 한 잔을 마셔요.
绿色|绿(푸르다) + 色(빛깔) → 초록색|春天到了，树都变成绿色了。|봄이 와서 나무가 모두 초록색이 됐어요.

没意思|没(없다) + 意思(재미) → 재미가 없다|这个电影真没意思。|이 영화 정말 재미없어요.
每||我每天早上跑步。|나는 매일 아침 달리기를 해요.
门||请关门。|문 좀 닫아 주세요.
门口|门(문) + 口(입구) → 문 입구|我在学校门口等你。|학교 정문 앞에서 기다릴게요.
门票|门(문) + 票(표) → 문을 들어가는 표 = 입장권|公园的门票多少钱？|공원 입장권 얼마예요?

奶茶|奶(우유) + 茶(차) → 우유 넣은 차 = 밀크티|我想喝一杯奶茶。|밀크티 한 잔 마시고 싶어요.
